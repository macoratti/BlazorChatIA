# Blazor IA Chat com GitHub Models

Este projeto demonstra como integrar **Modelos de Linguagem (LLMs)** em uma aplicação **Blazor Server** usando a abstração **Microsoft.Extensions.AI** e os **GitHub Models**.

A aplicação implementa um **chat simples com o modelo GPT-4o**, permitindo que o usuário envie perguntas e receba respostas diretamente de um modelo de IA.

---

# 🚀 Tecnologias Utilizadas

- **.NET / ASP.NET Core**
- **Blazor Server**
- **Microsoft.Extensions.AI**
- **Microsoft.Extensions.AI.OpenAI**
- **GitHub Models**
- **OpenAI SDK compatível**
- **CSS Isolation**
- **Dependency Injection**

---

# 🧠 Conceitos Demonstrados

O projeto explora vários conceitos importantes do ecossistema .NET moderno:

- Integração com **LLMs (Large Language Models)**
- Criação de um **Chatbot com Blazor**
- Uso da abstração **Microsoft.Extensions.AI**
- Integração com **GitHub Models**
- Uso de **User Secrets para proteger chaves de API**
- Uso de **Dependency Injection**
- **Separação de responsabilidades** entre UI e serviços
